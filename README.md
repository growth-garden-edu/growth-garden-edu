# 🌱 성장 정원 — 생활 루틴 실천 오픈 소스 템플릿

학생 한 명의 **생활 루틴 다짐**이 퍼즐 한 조각이 되고, 모두의 다짐이 모여 **그림을 함께 완성**하는 웹 메타버스 공간이에요.
파일 몇 개만 바꾸면 **우리 학교 정원**이 돼요. 코딩을 몰라도 괜찮아요.

> 📗 처음이라면 **`수정방법.html`** 을 더블클릭해서 열어 보세요. 순서대로 안내해요.

## 한눈에 보는 구조
```
참여 3단계   ①다짐 고르기(마음·몸·배움)  →  ②다짐하기(성장 문장 카드 선물)  →  ③퍼즐 조각 저금
조각 구조    다짐 1번 = 1조각  →  100조각 = 그림 1점  →  300조각(그림 3점) = 앨범 1권  →  2권으로 이어짐
```
- 앱 설치·회원 가입 없이 링크(QR) 하나로 참여해요. 이름·연락처 같은 개인정보는 받지 않아요.
- 성장 카드 7장(일주일 분량)을 모으고, 카드 이미지를 저장하거나 카톡으로 보낼 수 있어요.
- **성장 문장 출처:** 조선 중기 학자 우계 성혼(1535~1598) 선생이 제자들을 위해 남긴 공부방 규칙 「서실의」를 현대어로 풀어 쓴 문장이에요.

## 폴더 안에 있는 것
| 파일 | 하는 일 | 바꾸기 |
|---|---|---|
| `index.html` | 정원 화면 전체 | 맨 위 **SCHOOL 설정**만 바꾸면 돼요 |
| `principal.png` | 왼쪽 안내 캐릭터 | 우리 학교 캐릭터로 교체 (세로로 긴 그림, 배경 투명) |
| `mascot_girl.png`, `mascot_boy.png` | 학생이 고르는 캐릭터 2개 | 학교 마스코트로 교체 (배경 투명) |
| `emblem.png` | 저금통 위 교표 | 학교 교표로 교체 (방패 모양, 배경 투명) |
| `scene.jpg` | 정원 배경 | 학교 그림·사진으로 교체 (세로 1088×1360 권장) |
| `flowersL.png`, `flowersR.png` | 흔들리는 꽃 | 그대로 써도 돼요 |
| `pic1.png`, `pic2.png`, `pic3.png` | 함께 완성할 그림 3점 | 가로:세로 4:3 (예: 1200×900) |
| `functions/`, `schema.sql`, `reset.sql` | 학교 전체 조각을 함께 세는 서버 | 손대지 않아도 돼요 |

## 1. 우리 학교로 바꾸기 (index.html 맨 위)
```js
const SCHOOL = {
  sub:   "작은 습관이 꿈으로 자라는",   // 제목 위 작은 글씨
  title: "우리 성장 정원",             // 큰 제목
  tag:   "우리 학교",                  // 제목 옆 @ 뒤 글씨
  hostName: "정원지기 선생님",          // 왼쪽 캐릭터 이름표
  people: "우리",                      // 함께 참여하는 사람들을 부르는 말
  sage:  "성장 정원",                  // 성장 문장을 주는 이
  ...
};
```
- **`ROUTINES`**: 마음·몸·배움 다짐 목록 (달마다 바꿔도 좋아요)
- **`CARDS`**: 다짐하면 받는 성장 문장 7장. 기본은 우계 성혼 「서실의」 현대어 번역이에요. 학교 교훈이나 지역 인물의 글로 바꿀 때는 `s`(출처)도 함께 고쳐 주세요.
- **`GOAL`**: 앨범 1권의 조각 수 (기본 300). 3으로 나누어떨어지고, 그림 1점 조각 수(`GOAL ÷ 3`)로 `COLS × ROWS`가 나누어떨어져야 해요.

## 2. 인터넷에 올리기
### 가장 쉬운 방법: 깃허브 페이지 (5분, 조각은 기기마다 따로 저장)
1. github.com → **＋ → New repository** → 이름 예: `growth-garden` → **Public** → Create
2. **uploading an existing file** → 폴더 안의 파일을 모두 끌어다 놓기 → **Commit changes**
3. **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://(아이디).github.io/growth-garden/` 주소가 생겨요.

### 학교 전체 조각을 하나로 세는 방법: 클라우드플레어 (약 25분, 무료)
1. 위와 같이 깃허브 저장소에 올려요.
2. dash.cloudflare.com → **Storage & Databases → D1 → Create** → Console에 `schema.sql` 내용을 붙여 넣고 실행
3. **Workers & Pages → Create → Pages → Connect to Git** → 저장소 선택
   - Framework preset **None** · Build command **exit 0** · Build output directory **/**
   - Worker 만들기 화면으로 가면 아래 **Looking to deploy Pages? → Get started**를 눌러요.
4. 프로젝트 **Settings → Bindings → Add → D1 database** → 변수 이름 **DB** → 저장 후 다시 배포
5. `https://(프로젝트).pages.dev/api/state` 에 숫자가 보이면 성공이에요.
   - `GOAL`을 바꿨다면 `functions/api/[[path]].js` 맨 위 `TOTAL`(그림 1점 조각 수)도 맞춰 주세요.
   - 처음부터 다시 하려면 D1 콘솔에서 `reset.sql`을 실행해요.

## 3. 운영 팁
- 같은 기기에서 연속으로 누르면 3초 동안 잠겨요. (`LOCK_SECONDS`)
- 주소 끝에 `?admin`을 붙이면 시연용 버튼(마지막 1조각 전으로 이동)이 나와요.
- 받은 카드와 고른 캐릭터는 학생 각자의 기기에만 저장돼요.
